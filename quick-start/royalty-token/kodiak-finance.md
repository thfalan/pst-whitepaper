# Kodiak Finance

LiquidRoyalty uses Kodiak Finance to create liquidity pools. Users who are familiar with Kodiak can swap directly on [Kodiak](https://app.kodiak.finance/#/swap?chain=berachain_mainnet\&inputCurrency=0x5d3a1Ff2b6BAb83b63cd9AD0787074081a52ef34\&outputCurrency=0x59a61B8d3064A51a95a5D6393c03e2152b1a2770) without going through LiquidRoyalty—connect a wallet via that link and swap.
